# Machine Learning

This repository contains notebooks, datasets, revision material, and study guidance for the Machine Learning module.

## Start Here

Read the [complete study map](STUDY_MAP.md) before opening the notebooks. It explains the order of the topics and how each week supports the next one.

Each week contains a beginner-friendly [study guide](week1/STUDY_GUIDE.md) with:

- learning objectives and prerequisites;
- concepts to understand before coding;
- a suggested study sequence;
- practical exercises;
- a mastery checklist;
- the connection to the following week.

The guides are available in `week1` through `week11` and in `Project`. The notebooks remain the practical reference material for the corresponding topics.
